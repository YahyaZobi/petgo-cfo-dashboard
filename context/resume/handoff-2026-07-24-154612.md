## Key Decisions Made (standing architecture — learn these before editing)
- **Single-file app.** Everything lives in one HTML file with inline JS. Edits are surgical string replacements against a very large file. Per memory, the file has **giant base64 lines** — read targeted ranges (grep/sed to locate), don't dump the whole thing.
- **Two independent currency systems** (this is the #1 source of bugs — see [[vantage-dashboard-currency]] / [[vantage-payslip-currency]]):
  1. **Dashboard (Home → Finance Overview):** topbar `#pv-currency` toggle drives an IIFE-private `fmtMoney(base,dec,unit,cur)` with `RATES={LYD:1, USD:0.1634, EUR:0.191}` → `.pv-money[data-base]` values are **LYD-base**.
  2. **All Phase-2 modules (Pipeline, Budgets, Projects…):** global `fmtMoney(v)` + `currentCurrency` from `CURRENCIES` (USD rate 1, LYD 6.12) → values stored **USD-base**, switched only via Settings.
  - Putting module data on the Dashboard requires converting USD→LYD-base (`usd / 0.1634`) before writing `data-base`. The **Pipeline Forecast card (`renderPvForecast`)** is the reference pattern: mirrors rates as `PF_RATES`, reads active currency from `#pv-currency button.is-active`, re-renders via a bubbled click listener, and refreshes through *wrapped* `pvPageShown`/`pvOnThemeChange`/`pvOnAppShown` globals — **not** a `PV_PAGE_RENDER['Dashboard']` entry (that would re-run the card stagger on every revisit).
- **Payroll is LYD-native**, but global `fmtMoney` assumes USD-base → mislabels/double-converts. Payslip was fixed with its own native `_psMoney` (`'LD ' + toLocaleString`).
- **Modals must sit INSIDE `.pv-dashboard`** or they lose font/tokens/theme ([[vantage-modal-scoping]]).
- **Card shadows** use layered per-theme `--pv-shadow-tile/card/hover` tokens with **negative spread** (prevents stacked-card hourglass bleed). Never hardcode a card `box-shadow`; card gap 16–24px ([[vantage-card-shadows]]).
- **Avatars:** shared `empLookup`/`empAvatarInner`; match **email→name→empId** (empId is unreliable) ([[vantage-avatar-system]]).
- **Pipeline employees are keyed by NAME** (no empIds exist there); Pipeline money is **USD-base** ([[vantage-pipeline]]).
- **Tenders:** `noc.ly` has **no publish date, only expiry**; dual-side fuzzy matching must stay in sync between `lib/tenders.mjs` and `rpTnMatch` ([[vantage-tenders]]).
- **Reports rail** uses a panel-less pattern (`!NAV[cat]`) with `petgo_rp_*` stores ([[vantage-reports]]).
